The idea

Project overview

This project focuses on making banking code easier to test. Transaction logic was separated from interface concerns so that automated checks could exercise important behavior directly. A completed test run reported 96 passing tests.

The goal

Check meaningful transaction behavior and boundary conditions while making the code easier to understand, maintain, and test.

What it includes

Key features

  • Automated checks for transaction behavior.
  • Validation of invalid and nonpositive amounts.
  • Checks around insufficient funds and other edge cases.
  • A reporting reference requirement at the $10,000 limit.
  • A completed automated test run with 96 passing tests.

What I learned
