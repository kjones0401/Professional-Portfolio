# Bath County Youth Football Registration — Project Documentation

A web-based community registration and administration project that brings together enrollment, payment pathways, and operational reporting.

## Problem

Families and youth football organizers needed a structured approach to registering players and keeping information available to parents, coaches, and administrators.

## Key features described in the portfolio

- Parent registration and multi-player enrollment
- Player pricing and multiple-child discounts
- Payment options using Square links
- Parent, coach, and administrator dashboards
- Equipment tracking and registration reports

## Implementation

The project uses HTML, CSS, and JavaScript for the browser interface and Google Apps Script with Google Sheets for data processing/storage. The portfolio case study describes the public-facing UI and the operational workflows.
