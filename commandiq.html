Desktop application / Python & APIs

CommandIQ.

A personalized desktop command center designed to bring daily essentials into one place—live weather, assignments, meetings, reminders, humor, and a locally hosted AI assistant.

Role
Design, development & testing
Built with
Python · CustomTkinter · SQLite
Integrations
Open-Meteo · Blackboard ICS · Ollama

Application overview

The goal

Build a desktop application I could keep open throughout my day while learning to connect Python with external data sources and an AI assistant. The GUI prioritizes readable, high-contrast cards and easy access to common actions.

What it does

  • Displays the current date and an updating local clock.
  • Retrieves weather by ZIP code using Zippopotam.us and Open-Meteo.
  • Reads Blackboard calendar deadlines for the current week.
  • Saves meetings and reminders locally through SQLite.
  • Answers chat questions using a local Ollama/Gemma model, with a separate news-feed integration for headlines.
  • Offers an interactive “Daily Dose of Sass” card for humor.

Technical decisions and learning

APIs and integration

Python uses HTTP requests to obtain ZIP-coordinate and weather data. Blackboard deadlines come from an ICS calendar feed, while the AI assistant accesses a model through Ollama's localhost HTTP API. The clock and saved reminders use built-in/local Python services rather than external web APIs.

Iteration and troubleshooting

Development included testing API connections outside the GUI, fixing missing Python dependencies, switching from a paid cloud API to locally hosted AI, handling slow responses, and refining the dashboard layout through screenshots and testing.

Key takeaway

CommandIQ demonstrates how a Python desktop GUI can bring together remote information, local persistence, and on-device AI in a cohesive user experience. The project also reinforced the importance of authentication, error handling, performance, and documenting AI-assisted development.
