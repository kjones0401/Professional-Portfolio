Wildcats
Photography Hub

A responsive photography and video gallery for Bath County football families—paired with a separate data-management interface that makes maintaining the season's albums simple.

Explore Photography Hub ↗View Source Code ↗Explore the solution ↓

Project overview

The challenge

Game-day images were shared across multiple Google Photos albums. Families needed an intuitive place to discover the gallery for a particular opponent or event without navigating a long list of separate links.

The solution

I designed a single football photography destination with a dramatic photo-first header, instant gallery-name search, compact album cards, direct Google Photos links, and a dedicated gallery editing workflow.

HTML5CSS3Vanilla JavaScriptJSONResponsive UIGitHub Pages

What I built

Designed for visitors. Built for easy maintenance.

01 / VISUAL DESIGN

Photo-first experience

A cinematic football entrance image leads the page, with the title below the photograph so the players remain fully visible.

02 / DISCOVERY

Instant gallery search

Families can filter albums by opponent, event name, category, or description without leaving the page.

03 / RESPONSIVE UI

Compact album cards

Responsive grid cards adapt across desktop and mobile while linking directly to their matching Google Photos galleries.

04 / DATA MODEL

JSON gallery records

Album title, category, description, date, and external gallery URL are stored as reusable structured records.

05 / MANAGEMENT

Separate admin editor

A locally used administration page supports editing records and importing/exporting JSON, keeping the editor separate from the public gallery.

06 / PRACTICAL UX

Community-first access

Visitors can browse and access shared albums without a new account or an additional photo storage platform.

The public experience reads the gallery data from a JSON file. Publishing changes is deliberately separate from editing: updating the hosted JSON file requires access to the repository. The local editor itself does not provide public write access.

Design decisions

Practical details matter

I chose client-side search for immediate results, compact cards for efficient browsing, and native HTML controls that work with keyboard navigation. The page also supports reduced-motion preferences.

Reflection

Beyond a static webpage

This project combined UI design and content organization with a real maintenance workflow: editing structured data separately from the display layer. It demonstrates my interest in useful interfaces and thoughtfully designed operational tools.

Source code & documentation

The public gallery page is maintained in its GitHub repository. The separate gallery editor stays on the project owner’s computer.
